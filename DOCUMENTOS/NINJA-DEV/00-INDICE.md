# Guía operativa de Ninja Dev

Ninja Dev es el área de desarrollo de software de Ninja Tech para pymes peruanas. Esta guía sirve para ejecutar un proyecto y como contenido futuro de la plataforma. Los ejemplos son orientativos: el alcance, los plazos y los niveles de servicio de cada cliente se fijan por escrito.

## Regla de uso

1. Abrir una carpeta de proyecto con identificador, cliente, responsable y fecha.
2. Copiar las plantillas de [03](03-DOCUMENTOS-DEL-PROYECTO.md) que correspondan. Mantener versión, autor y aprobación en cada documento.
3. Registrar decisiones, riesgos, cambios de alcance, pruebas y conformidad con enlaces a evidencia.
4. Compartir con el cliente solo los documentos aprobados para él; conservar los internos bajo acceso restringido.

La propuesta comercial, las tarifas reales y los contratos viven en el repositorio privado `ninjasec-empresa`. Esta guía no los reemplaza.
